연출컷 제작

제품 사진과 원하는 연출을 모아, 이미지 생성용 프롬프트를 완성하세요.

설치·로그인 없이 사용하는 개인 작업 도구

01 · 사진 준비

사진은 이 브라우저 안에서만 사용합니다. 원래 파일명과 각 사진의 역할을 프롬프트에 자동으로 표시합니다. 선택한 원본 사진과 프롬프트를 GPT에 함께 첨부하세요.
구도·배경·제품을 놓는 모습에 각각 여러 사진을 올려 보세요. 시안마다 어울리는 후보를 골라 자유롭게 조합하도록 안내합니다. 한 항목에 한 장만 있어도 시작할 수 있어요.

분할 없이 각각 한 장씩 요청합니다. 외부 이미지 생성 도구에서도 같은 장수를 선택하세요. 이 도구는 프롬프트를 작성하며 실제 출력 장수를 제어하지는 않아요.

방식을 바꿔도 등록한 사진은 유지됩니다. 현재 방식의 사진만 프롬프트에 포함됩니다.

필요한 역할만 골라 한 장 이상 등록하세요. 비워 둔 항목은 선택한 요소와 어울리게 자연스럽게 보완합니다.

참고 사진의 역할을 정해요

비워 두어도 괜찮아요. 적으면 선택한 참고 방식 안에서 반영합니다.

02 · 제품과 연출

형태·색상·소재·로고·봉제선·부속 보존, 소품과의 실제 크기 관계, 자연스러운 그림자는 기본 지시문에 포함됩니다.
모르면 비워 두세요. 소재 디테일 사진을 기준으로 짜임·광택·주름을 보존하도록 안내합니다.
착용컷은 크기 비교에만 사용하고 모든 결과에서 사람을 제외하도록 안내합니다. 키는 크기 참고컷이 있을 때만 적용하며 제품 실측 치수를 우선합니다.
빈칸이면 제품 전체가 잘 보이도록 안내합니다. 없는 특징을 새로 만들지는 않도록 지시합니다.
참고 사진에서 가져오지 않을 항목 · 추가 강조

해제해도 제품 보존 기본 원칙은 계속 적용됩니다.

03 · GPT 이미지 생성용 프롬프트

등록할 때 사용한 원본 사진들을 아래 프롬프트와 함께 GPT에 첨부하세요. 프롬프트에 원본 파일명과 정면·하단·소재 디테일·참고 사진 등의 역할이 표시됩니다.

입력한 글은 이 브라우저에 임시 저장합니다. 사진은 파일을 다시 열거나 새로고침하면 재등록해야 합니다.
HTML 파일을 더블클릭해서 사용하세요. 원본 파일명에 사진 역할을 연결하는 프롬프트 작성은 인터넷 없이 동작합니다.
