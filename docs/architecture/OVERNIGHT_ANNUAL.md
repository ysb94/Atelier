# 밤샘 외근 다음 날 연차

- 전날 시작한 밤샘·연속 외근이 연차 첫날의 출근 기준 시각까지 종료되면 연차와 함께 등록할 수 있다. 정각 종료도 허용한다. 연차 먼저/외근 먼저 및 단체 외근 모두 같은 서버 검증을 사용한다.
- 기준은 연차일의 월별 직원 우선·부서 설정과 유효한 당일 출근 기준이다. 전날에만 지정한 출근 기준을 다음 날로 넘기지 않는다. 기준이 없으면 임의의 09시/18시를 적용해 예외를 허용하지 않는다.
- 예: 11/4 16시~11/5 05시 외근과 11/5 연차는 허용한다. 11/5 출근 기준 09시이면 09시 종료까지 허용하고 09:01은 차단한다. 10시 기준이면 10시 종료까지 허용한다.
- 같은 날 별도로 시작한 외근, 연차일 낮까지 계속되는 외근, 공가 등의 기존 충돌은 유지한다. 연차 차감과 출퇴근 원본·자동 종료·야근/외근 후처리는 변경하지 않는다. 기존 신청은 소급 수정하지 않는다.
- 화면은 신청 전 필요한 날짜의 본인 근무 기준을 조회해 중복 검사를 한다. 서버는 기존 직원 잠금과 신청 검증을 유지한 채 연차/외근 쌍에만 예외를 적용한다. 출근 기준 변경·해제로 이미 허용한 조합이 충돌하게 되는 경우도 서버에서 차단한다.

## 검증과 적용

- `npm run verify:overnight-annual`: 양쪽 등록 순서, 05시/09시/09:01/10시 경계, 월별·당일 기준과 전날 기준의 구분, 연속 외근, 기준 미설정, 기존 충돌·권한·원본 보존을 격리 DB와 실제 신청 컴포넌트에서 검증한다.
- 로컬 마이그레이션 `20261104035650_overnight_offsite_annual_overlap.sql`을 준비했다. **공유 DB 미적용**이며 적용 승인 후 서버 검증까지 변경해야 실제 신청이 허용된다.
- 적용 전 함수·실행 권한 복구본은 `docs/backups/overnight-annual-functions-before-20261104.json`에 보관한다. 공유 DB 적용 시 원본·기존 정책·권한을 보존하고 실제 인증 역할 검증은 별도 허용 범위를 따른다.
