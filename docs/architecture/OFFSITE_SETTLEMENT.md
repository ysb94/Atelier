# 연속 외근과 외근 후처리

2026-11-03 로컬 코드·추가 SQL 준비. **공유 운영 DB 미적용, main 미배포.**

- 시작·종료 날짜/시각을 입력하며 24시간 상한을 없앴다. 24시간 이하는 기존 단일 근무일 저장 형식을 유지한다. 더 긴 구간만 `offsite_continuous=true`와 실제 날짜를 저장한다. 기존 반복 외근 행은 false 그대로이며 평일 반복 의미를 유지한다.
- 연속 외근은 주말·공휴일을 포함한다. 출퇴근은 시작 근무일 한 건을 유지하고 실제 종료 날짜/시각에 자동 퇴근한다. 자정·여러 날 경과·사무실 복귀·직접 퇴근을 연결한다. 기존 수동 기록과 자동 처리 활성화 시각은 보존한다. 회의 시간표는 실제 시작~종료 날짜 범위를 사용한다.
- 운영지원 외근 관리는 예정·진행 중·종료·취소와 후처리 대기를 구분한다. 정규 근무 내 외근은 별도 보상 없이 넘어간다. 기준 미설정은 임의로 0시간 처리하지 않는다.
- 종료된 외근의 날짜별 예상 추가 근무를 보여주고, 운영지원이 실제 근무 분을 직접 입력한다. 숙박·휴식·이동을 모두 야근으로 추정하지 않는다. 월별 직원/부서 출근 기준, 시작일의 당일 기준 변경, 점심, 등록 휴가, 공휴일을 반영한다. 입력 시점의 서버 기준으로 다시 검증한다.
- 처리 방식은 야근 누적 / 추가 휴가 지급 / 실제 추가 근무 없음이다. 휴가는 .25일 단위(반반차·반차·연차 및 합산)와 사용기한을 직접 정한다. 기존 추가 연차 저장 함수를 재사용하고 기본 연차 잔액을 덮어쓰지 않는다.
- `offsite_settlements`는 외근당 확정 이력 하나다. 직원별 공통 잠금 아래 검증·휴가 지급·이력을 한 트랜잭션으로 저장한다. 같은 성공 요청 재시도는 추가 지급 없이 성공하고 다른 두 번째 처리는 충돌한다. 이미 확정한 외근과 지급 휴가는 직접 취소/수정하지 못하게 보존한다.
- 야근 방식만 기존 실제 야근 조회에 연결한다. 날짜별 확인 분을 해당 월에 귀속해 운영지원과 My home에서 같은 값으로 합산한다. 휴가 방식은 야근 0분이다. 늦은 퇴근만으로 누적하지 않는다.
- 겹치는 별도 야근 실제 기록이 있으면 후처리를 차단하고, 이미 후처리한 외근과 겹치는 실제 야근 보고도 차단한다. 기존 야근 신청·승인 권한 자체는 바꾸지 않는다.
- 관리 저장/예상 조회는 기존 추가 연차 관리 권한(`can_edit_org_assignment` 또는 `basic_work_allowed('operations')`)과 활성 계정/회사 경계를 재사용한다. 이력 조회는 기존 원본 신청 RLS를 따른다. 공개 RPC는 invoker, 권한 확인이 필요한 내부 함수는 비공개 app에 두고 익명 실행을 차단한다.
- 직원 결과 알림은 후처리 성공 때만 생성한다. 기존 종합 알림/My Schedule 서버 목록·상세 경로·읽음 표를 공유한다. 상세 내 후처리 결과가 정상 표시된 뒤에만 정확한 이벤트 키를 읽음 저장한다. 직원 본인에게만 가며 추가 응답은 요구하지 않는다. 과거 완료 결과를 소급 생성하지 않는다.
- 준비 SQL: `20261103102914_offsite_continuous_settlement.sql`. 선행 SQL `20261103090128_offsite_workday_start_override.sql`이 필요하다. 기존 함수 본문에 좁은 치환을 적용하므로 적용 직전 운영 소스 비교·보존 검사가 필요하다. 기존 함수 ACL/소유자/잠금 설정과 기존 RLS·원본 행은 재작성하지 않는다.
- 운영 스키마 읽기 전용 확인: 당일 출근 기준 함수와 이번 연속 외근/후처리 표·열이 아직 없다. 실제 사용에는 두 추가 SQL의 적용 승인이 필요하다. 직원 원문은 조회·반출하지 않았다.
- 검증: `verify:offsite-continuous`, 기존 `verify:offsite-overnight`·`verify:overtime-actuals`, Node 22 build, diagnostics, structure-map. 격리 DB/로컬 브라우저 데이터만 사용한다.

운영 DB 적용은 별도 승인 대상이며, 이 문서의 준비 상태를 실제 사용 가능으로 보고하지 않는다.
