# 일반 Chrome 스마트스토어 읽기 시험

현재는 **실험 도구**이며 기존 가격 최신화 경로를 변경하지 않는다.
일반 Chrome에서 상품이 열리는지, 확장으로 본상품의 표시 본문을 읽을 수 있는지 확인한 뒤 연결한다.

1. `node scripts/md-price-extension/probe-server.mjs`를 실행한다. 한 시간 동안 이 PC의 loopback 주소에서만 결과를 받는다.
2. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 `.tmp/md-smartstore-extension` 폴더를 선택한다.
3. 평소 사용하는 Chrome에서 `https://smartstore.naver.com/masmarulez/products/13243466853`를 연다.
4. 확장 메뉴에서 **Atelier 스마트스토어 읽기 테스트**를 선택하고 **상품 본문 읽기**를 누른다.
5. `테스트 결과 저장 완료`가 나오면 `.tmp/md-smartstore-extension-results/`의 JSON과 실제 화면 상품명·가격을 비교한다. 수신기 콘솔에도 성공·실패가 남는다.

권한은 `activeTab`, `scripting`, `http://127.0.0.1/*`이다. 누른 현재 탭에만 일시 접근하며 코드상 마스마룰즈 스마트스토어 상품 경로만 허용한다.
쿠키·비밀번호·다른 탭·페이지의 내부 상태·전체 HTML을 읽지 않는다. 보이는 상품 제목·가격 주변 본문·구매 버튼 문구를 수집한다.
상품 영역이 불명확하면 전체 페이지를 대신 보내지 않는다. 입력 요소·헤더·탐색·추천·리뷰는 제외한다.
페이지가 표시하는 로그인이나 보안 확인을 자동으로 수행하지 않는다.

결과는 브라우저에서 로컬 수신기로만 전송한다. AI API나 Supabase에는 보내지 않으며 가격 DB도 바꾸지 않는다.
수신기는 생성한 확장 ID의 Origin, 이번 실행의 임의 토큰, 본문 한도를 검사하며 최대 5건을 받는다.
수신기 재시작 후에는 확장 팝업을 다시 열면 새 설정을 읽는다. 소스 파일을 바꿨다면 수신기를 재시작하고 Chrome 확장도 새로고침한다.

검증 순서: 로컬 코드/DOM 검증 → 일반 Chrome 수동 클릭 읽기 → 화면 가격 대조 → 실제 링크 2–3개 연속 읽기 → 그 뒤에만 가격 최신화 통합.
테스트가 끝나면 확장을 삭제하거나 꺼 둘 수 있다. 앱 적용 전까지 자동으로 탭을 열거나 주기적으로 수집하지 않는다.
