한 단계씩 확인하고 넘어갑니다

지금은 0단계 · 운영 미적용
  1. 0. 지금: 읽기 전용 점검

    현재 계정·승인 상태·승인자 원본과 DB 규칙을 기록하고, 사람별 전환표와 복구를 로컬에서 검증합니다.

  2. 1. 별도 승인 후: 새 저장소만 준비

    기존 함수·접근 규칙·트리거를 바꾸지 않습니다. 새 권한 지정 API는 잠그고 기존 로그인과 승인 절차를 유지합니다.

  3. 2. 전환 직전: 변경 중지·최신 비교

    권한·조직·승인자 편집 중지를 유지하고 확정한 기준과 현재 데이터·서버 규칙을 다시 비교합니다. 호환 앱·서버·복구 파일이 준비되지 않으면 진행하지 않습니다.

  4. 3. 별도 승인 후: 서버 전환과 앱 활성화

    기존 데이터 지문을 확인한 뒤 권한 이관과 서버 규칙 교체를 한 트랜잭션으로 처리합니다. 오류가 나면 함께 취소됩니다. 이후 호환 서버와 앱을 전환하고 기존 탭도 새로 고칩니다.

  5. 4. 문제가 생기면: 서버 규칙 복구

    권한 편집을 멈추고 기존 함수·실행 권한·접근 규칙을 복원한 뒤 호환 서버·앱을 되돌립니다. 사용자나 승인자를 옛날 사본으로 덮어쓰지 않습니다. 화면 스위치만 끄는 것은 복구가 아닙니다.

검증 결과

운영 DB에서 전환한 결과가 아닙니다.
운영 적용 전 남은 확인: 권한 관리자 후보 확정, 최신 스냅샷 재생성, 기존 앱·서버 호환 배포, 대표 사용자 실제 로그인·허용/차단 동작 확인. 이 화면에서 SQL을 실행할 수 없습니다.
