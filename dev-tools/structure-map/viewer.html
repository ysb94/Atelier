기능의 ＋를 눌러 펼치고, 항목을 선택하면 사용하는 코드와 이 코드를 사용하는 곳을 확인할 수 있습니다. 지도의 빈 곳을 드래그해 이동하고, Ctrl + 휠 또는 아래 버튼으로 확대하세요. 검색 결과를 선택하면 해당 파일까지 펼쳐집니다.

npm run dev를 실행하면 Atelier와 구조도 서버가 함께 켜집니다. 구조도 주소는 http://127.0.0.1:4318/이며 코드 변경을 자동 반영합니다. 구조도만 사용할 때는 npm run structure:map:watch, HTML 스냅샷만 갱신할 때는 npm run structure:map을 실행합니다.

전체 총람에서 공통 기반을 포함한 모든 기능·코드·데이터 자원을 스크롤로 읽을 수 있습니다. 항목을 누르면 지도와 코드 상세로 이동합니다. 지도 모두 펼치기는 전체 구조를 한 번에 펼칩니다. 파일을 선택해도 다른 기능은 유지하며, 기능 요약으로 다시 접을 수 있습니다.

한글 기능명을 먼저 표시하고 파일명은 선택한 항목의 상세에서 확인합니다. 기능명은 화면 제목·메뉴명에서 자동 추출하며, 제목이 없는 코드는 공통 한글 용어 규칙으로 추정합니다. 역할 설명의 추출·추정 근거도 상세에서 확인할 수 있습니다. 새 파일과 연결을 하나씩 직접 등록할 필요는 없습니다.

연결은 소스의 import·동적 import·Web Worker·API 위임·명시적 테이블/RPC/Storage/Edge 호출을 분석한 결과입니다. 실행 흐름, 모든 함수 호출, SQL 함수 내부 의존, RLS 또는 실제 DB 스키마를 검증한 결과는 아닙니다. 타입 연결은 기본 숨김이며, 리다이렉트는 별도로 표시합니다.
