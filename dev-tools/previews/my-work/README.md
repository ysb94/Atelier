# 내 업무 UI 시안

노션의 직접 할 일 메모를 바탕으로 사원·팀장 화면을 구성했다.

- 사원: 내 업무의 출처 구분, 상태별 보드·리스트, 검색, 업무 추가, 하위 할 일, 업무별 대화.
- 팀장: 내 업무에 더해 팀원별 현황, 팀 업무, 피드백 확인, 부서 간 대화.
- 회사·팀 공지와 확인 표시, 기존 부서별 작업 요청 링크를 유지한다.
- 멤버·권한 메뉴는 기존 표시 권한을 유지하면서 운영지원 그룹으로 옮겼다.

앱의 `/work`에서 로그인한 프로필의 이름·소속·직책을 사용한다. 팀장·이사·대표이사는
팀 화면이 열리고, 그 외에는 사원 화면이 열린다. 화면에서 역할을 바꾸지는 않는다.
업무·공지·대화는 예시 데이터이고 React 상태에서만 바뀐다. 실제 저장·실시간 공유·알림을
구현하지 않았으며 새로고침하면 예시의 초기 상태로 돌아간다.

로그인 없이 시안을 확인하려면 Vite를 실행한 뒤
`/dev-tools/previews/my-work/index.html`을 연다. 예:

```bash
npm exec vite -- --host 0.0.0.0 --port 5174
```

검증: Node 22 빌드, lint 오류 없음, 진단·탭 의존성·기존 권한/미리보기 검증 통과.
실제 Chromium에서 검색·출처/상태/담당자 필터, 하위 할 일 추가/체크/삭제, 대화,
피드백 상태 이동, 공지 확인, 새로고침 초기화와 390px 모바일 배치를 확인했다.
UI 시안의 동작 확인이며 실제 업무 데이터의 저장이나 운영 사이트 반영을 뜻하지 않는다.
